# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 개인의 기술 역량, 프로젝트, 연락처를 한눈에 보여주는 프로필(포트폴리오) 웹사이트 |
| 주 개발분야 | Python, HTML5 |
| 연락처 | smlim@infiniq.co.kr |
| 문서 작성일 | 2026-11-03 |

## 2. 배경 및 목표

### 배경
- 채용 담당자, 협업 파트너, 고객에게 개발자의 역량을 빠르게 전달할 수 있는 단일 창구가 필요하다.
- 이력서·GitHub·이메일로 흩어진 정보를 하나의 웹페이지로 통합한다.

### 목표
1. 방문자가 30초 안에 "누구인지, 무엇을 잘하는지, 어떻게 연락하는지" 파악할 수 있다.
2. Python / HTML5 중심의 기술 스택과 대표 프로젝트를 명확하게 보여준다.
3. 별도 서버 없이 정적 호스팅(GitHub Pages 등)으로 배포 가능하다.

### 성공 지표
- 모든 주요 섹션이 모바일·데스크톱에서 깨짐 없이 표시된다.
- Lighthouse 점수: Performance / Accessibility / Best Practices / SEO 각 90점 이상.
- 이메일 연락 버튼이 정상 동작한다(`mailto:` 링크).

## 3. 대상 사용자

| 사용자 | 니즈 |
|--------|------|
| 채용 담당자 / 면접관 | 기술 스택, 경력, 대표 프로젝트를 빠르게 확인 |
| 협업 개발자 | 코드 스타일, 사용 기술, GitHub 저장소 확인 |
| 잠재 고객 / 의뢰인 | 수행 가능한 작업 범위와 연락 방법 확인 |

## 4. 기능 요구사항

### 4.1 페이지 구성 (싱글 페이지, 섹션 스크롤 방식)

| # | 섹션 | 내용 | 우선순위 |
|---|------|------|----------|
| 1 | Header / 내비게이션 | 이름(로고), 섹션 이동 메뉴, 모바일 햄버거 메뉴 | P0 |
| 2 | Hero (소개) | 이름, 한 줄 소개(예: "Python & HTML5 Developer"), 연락하기 CTA 버튼 | P0 |
| 3 | About (자기소개) | 간단한 경력 요약, 개발 철학, 관심 분야 | P0 |
| 4 | Skills (기술 스택) | 주력: Python, HTML5 / 보조: CSS3, JavaScript, Git 등. 카테고리별 배지 형태로 표시 | P0 |
| 5 | Projects (프로젝트) | 프로젝트 카드(제목, 설명, 사용 기술 태그, GitHub/데모 링크) | P0 |
| 6 | Experience (경력) | 타임라인 형식의 경력·교육 이력 | P1 |
| 7 | Contact (연락처) | 이메일(smlim@infiniq.co.kr) `mailto:` 링크, 이메일 복사 버튼, GitHub 등 외부 링크 | P0 |
| 8 | Footer | 저작권 표기, 최종 업데이트 날짜 | P1 |

### 4.2 세부 기능

- **반응형 레이아웃**: 모바일(≤ 640px), 태블릿(≤ 1024px), 데스크톱 대응.
- **다크 / 라이트 모드**: 시스템 설정(`prefers-color-scheme`)을 따르고, 토글 버튼으로 전환. 선택값은 `localStorage`에 저장. (P1)
- **부드러운 스크롤 & 현재 섹션 하이라이트**: 메뉴 클릭 시 해당 섹션으로 이동, 스크롤 위치에 따라 메뉴 활성화. (P1)
- **이메일 복사**: 클릭 시 클립보드에 이메일 주소 복사 후 "복사됨" 피드백 표시. (P1)
- **프로젝트 데이터 분리**: 프로젝트·스킬 목록을 `data/profile.json`으로 분리해 코드 수정 없이 내용 갱신. (P1)
- **Python 정적 빌드 스크립트**: `build.py`가 `profile.json` + 템플릿으로 `index.html`을 생성(표준 라이브러리만 사용, 별도 설치 불필요). 주 개발분야인 Python을 프로젝트 자체에서도 보여주는 목적. (P2)

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| 기술 | HTML5 시맨틱 태그(`header`, `nav`, `main`, `section`, `footer`), CSS3, Vanilla JavaScript. 빌드 도구는 Python 3.10+ |
| 성능 | 외부 라이브러리 최소화, 이미지 WebP·지연 로딩(`loading="lazy"`) |
| 접근성 | WCAG 2.1 AA 준수: 대비율, `alt` 텍스트, 키보드 탐색, `aria-label` |
| SEO | `title`, `meta description`, Open Graph 태그, `lang="ko"` |
| 호환성 | 최신 Chrome, Edge, Safari, Firefox |
| 배포 | 정적 호스팅(GitHub Pages / Netlify). 별도 백엔드 없음 |
| 보안 | 이메일은 `mailto:` 링크만 사용, 외부 폼 전송 없음 |

## 6. 디렉터리 구조 (안)

```
DemoPort/
├── prd.md
├── index.html          # 메인 페이지 (build.py가 생성, 직접 수정하지 않음)
├── templates/
│   └── index.html      # 페이지 템플릿 ({{name}} 등 자리표시자)
├── css/
│   └── style.css
├── js/
│   └── main.js         # 메뉴, 테마 토글, 이메일 복사
├── assets/
│   └── images/         # 프로필 사진, 프로젝트 썸네일
├── data/
│   └── profile.json    # 스킬·프로젝트·경력 데이터
└── build.py            # JSON + 템플릿 → index.html 정적 빌드
```

- **톤**: 깔끔하고 미니멀한 개발자 스타일.
